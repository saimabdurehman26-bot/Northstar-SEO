# Northstar SEO

A Python-served SEO analytics dashboard demo. The interface includes a responsive overview, sample search metrics, keyword tracking saved in the browser, chart controls, and CSV export.

## Run

```powershell
python app.py
```

Then open [http://127.0.0.1:8000](http://127.0.0.1:8000).

To use a different port:

```powershell
python app.py --port 8080
```

No third-party Python packages are required. Dashboard analytics are illustrative demo data; added keywords are stored in this browser's local storage.
